# 🎣 つって おぼえる『すうじつり』

4さいごろの こどもが、**すうじを せおった さかな** を つりながら
**すうじ（0〜100・マイナス）・なんじ なんぷん・なんがつ なんにち・ようび・たしざん** を おぼえる ゲームです。

## あそびかた

### 1しゅうかん さかなを つる
- **にちようび から どようび まで** の 1しゅうかん（じっさいの カレンダーの ひにち）。1かい（1しゅうかん）は **5ふん くらい** で おわります
- 1にちは **あさ 6じ 〜 ゆうがた 16じ**。うえの とけい と じかんの ぼう（6〜24じ）で いまの じかんが わかります
- ようびが かわる ときは、がめん いっぱいに **にち げつ か すい もく きん ど** を ならべて 🐟 が ゆっくり つぎの ようびへ。
  「にちようびの つぎは… げつようび！」「10がつ 19にち げつようび」と よみあげます
- さいしょの 3にちは かんたん（にち: 10まで・げつ: 20まで・か: 30まで）。すい 50・もく 70・きん 90・ど 100 と だんだん おおきい すうじの さかなが でてきます

### つりかた（かんたん そうさ）
1. **つる ばしょ** を タップ（みずの 3かしょ）
2. **えさ** を えらぶ（さいしょは 🪱 ミミズ「1」だけ）
3. **「🎣 つる！」** ボタン
4. うきが しずんで **かかった！** → がめんを **れんだ** して ひきあげる（おおきい さかなほど たくさん）
5. 「**なんの すうじの さかなかな？ いってみよう。せーの！**」→ すこし まって こたえの すうじを よみあげます

### えさ
- つった さかなは バケツに はいって **えさに できます**（つかうと バケツから でます）
- えさの すうじが おおきいほど おおきい さかなが つれます。つれるのは **えさの さかなの しゅるいの まえと うしろ 3つまで**（おおきい ほうが でやすい）
- 👢 ながぐつ・🥫 あきかん・🧦 くつした は **マイナスの すうじ**。めったに つれません（えさには なりません）

### ⏰ じかんざかな
- とけいを せおった さかな。つると「なんじ なんぷんかな？ せーの！」
- 「**じかんざかなだ！ 3じ15ふんの さかなだったから、3じかん15ふん、のびた！**」と、その じこくの ぶん **おわりの じかんが のびます**
- おおきな とけいに ズームして、ながい はりが 1じかんずつ ゆっくり まわり（「1じかん、2じかん…」）、のこりの ふんも すすみます
- のびても **24じ（1にち）まで**。でて きすぎると たいへんなので **1しゅうかんに 3かい まで**（うえの ⏰⏰⏰）
- ようびが すすむと じこくが むずかしく なります（ちょうど → 30ぷん → 15ふん → 5ふん → 1ぷん きざみ）

### さいごに たしざん
- どようびが おわると、バケツに のこった さかなを 1ぴきずつ **「25 たす 30 は 55」** と ゆっくり たしざん（マイナスは「ひく」）
- ごうけいは どんなに がんばっても **1000 を こえない** ように なっています
- ごうけいは **🏆 ランキング**（10い まで）に のこります
- さいごに「**きょうは やめとく？**」→「まだ やる！」で つぎの しゅう（カレンダーも つぎの しゅうへ）、「やめとく」で おしまい
- あそんでいる とちゅうでも 🏠 で「やめとく？」が でます

## うごかしかた（Android）

アプリストアからは ダウンロードしません。**インターネット上に おいた ページを Chrome で ひらいて、ホームがめんに ついか** すると アプリとして つかえます（PWA）。いちど ひらけば オフラインでも あそべます。

1. GitHub の リポジトリ → **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main`（または この ブランチ）/ `/(root)` → **Save**
   （プライベートの リポジトリでは むりょうの GitHub Pages が つかえないので、**Settings → General → Change visibility → Public** に するか、Cloudflare Pages / Netlify を つかいます）
2. 1〜2ふん まつと `https://ryohei-yoshida-cpu.github.io/ren-game-math/` で ひらけます
3. Android の Chrome で ひらいて **「📲 ホームがめんに ついか」**（でない ときは ︙メニュー →「ホーム画面に追加」）

パソコンで ためす:

```sh
python3 -m http.server 8000
# → http://localhost:8000      （?speed=8 を つけると はやおくり・こえなしの テストモード）
```

## こえ について
こえは [VOICEVOX](https://voicevox.hiroshiba.jp/) で まえもって つくった おんせい（`audio/voice/*.mp3`）です。

| やく | こえ |
| --- | --- |
| ナレーション・すうじ（0〜1000）・とけい・カレンダー | VOICEVOX:春日部つむぎ |
| ねこ（「かかったのだ！」） | VOICEVOX:ずんだもん |

すうじや じこくは こえを つなげて よみます（「25|たす|30|は|55」「3じ|15ふん|の さかなだったから」など）。

### 🎙 じぶんたちの こえに する（こえの スタジオ）
「ひらがなまてまて」と おなじ しくみです。タイトルの **「🎙 こえ」** から、ぜんぶの セリフ（すうじ・とけい・カレンダーも）を じぶんたちの こえに とりかえられます。

- **●** で ろくおん → **■**。**▶** で きく、**↺** で もとに もどす
- **📨 えらんだ セリフを LINEで たのむ** → ともだちが リンクを ひらいて ろくおん → **「✅ できた！ おくりかえす」**（こえパック PDF）
- とどいた PDF を **「📥 こえを よみこむ」** で いれる
- **📤 とった こえを おくる** で バックアップ・おひっこし

### セリフを かえた とき（こえの つくりなおし）
`js/game.js` の `nar('...')` / `kid('...')` や `js/data.js` を かえたら、こえを つくりなおします（パソコン・Linux）。こえの ない セリフは ブラウザの よみあげで しゃべります。

```sh
node tools/voices/lines.mjs     # セリフを あつめる → tools/voices/lines.json
VV_DIR=/path/to/voicevox python tools/voices/gen.py   # ない ぶんだけ つくる → audio/voice/
```

`VV_DIR` には VOICEVOX CORE（0.16）の `voicevox_onnxruntime-linux-x64-1.17.3/`・`open_jtalk_dic_utf_8-1.11/`・`vvms/0.vvm` を おきます。python には `voicevox_core-0.16.x-...whl` を pip で いれ、ffmpeg も つかいます。

## ☁️ データを ほかの スマホと きょうゆう する
「ひらがなまてまて」と おなじ Firebase（`js/cloud-config.js`）と おなじ しくみです。タイトルの **「☁️ きょうゆう」** で ID を いれると、ずかん・ランキング・とった こえ が ウェブに ほぞんされます。

- 「ひらがなまてまて」で つかっている ID が あれば、さいしょから いれて あります。**おなじ ID でも データは まざりません**（ウェブでは `accounts/fish-<ID>` に ほぞん）
- Firestore の ルールは「ひらがなまてまて」の `firestore.rules` の ままで うごきます（あたらしい せっていは いりません）
- 「いま どうきする」で 🔀 まぜる（ずかんは おおきい ほう・ランキングは りょうほう）/ ⬇️ うけいれる / ⬆️ こうしんする が えらべます
- ⚠️ ID を しっている ひとは だれでも データを みたり かえたり できます。かぞく だけの ひみつに してください

### ほぞん
ずかん・ランキングは この スマホの ブラウザ（localStorage）にも ほぞんされます。タイトルの「さいしょから（おとなよう）」で リセットできます。
「ひらがなまてまて」と おなじ GitHub Pages に おいても、ほぞんの なまえ（`sujitsuri-...`）が ちがうので まざりません。
